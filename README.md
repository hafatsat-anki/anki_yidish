# אנקי אויף יידיש

Anki 25.9.2 מיט א יידישן ממשק און די תורה צוגאבן, אין חרדישער יידיש אן ניקוד.

## אראפלאדן און אינסטאלירן

דער Windows אינסטאלירער געפינט זיך אין [Releases](https://github.com/hafatsat-anki/anki_yidish/releases).
פאדערונגען: Windows 10 אדער 11, 64 ביט.

די ברירת מחדל תיקיה איז `%LOCALAPPDATA%\Programs\Anki Yidish`.
די פראגראם טעקעס ליגן אין `app`, און אייערע פעקלעך, פראגעס און צוגאב איינשטעלונגען אין `Data`.
די אויסגאבע האט א באזונדערן פראגראם מזהה און רירט נישט אן די דאטן פון אייער געווענליכן אנקי.
כדי צו עפענען מיט דער האנט:

```text
app\anki.exe -b Data -l yi
```

ביים דערהייבן ווערן עקזיסטירנדע איינשטעלונגען געגיבויט און צונויפגעמישט מיט די נייע ברירת מחדל ווערטן.
די שאלות, מקורות התורה, נעמען פון פעלדער און אימפארט חוזים בלייבן אין זייער אריגינעלן נוסח.
די מדריכים און FAQ זענען אינעם הילף מעניו. די לענגערע אלטע PDF מדריכים זענען מסומן אלס היסטארישע מדריכים;
פאר די יעצטיגע Windows און FSRS אנווייזונגען נוצט דעם אינערליכן מדריך.

## מקור און בויען

די תוסף מקורות זענען אין `addons/ankiweb`, `addons/custom` און `addons/torah`.
די געמיינזאמע ספריות זענען אין `shared_libs` (ביים אויסטיילן `_shared_libs`).
`config/addon_registry.json` האלט דעם מקור און אינסטאליר נאמען פון יעדן צוגאב.
דער זעלבסטשטענדיגער יידיש ממשק פון אנקי איז אין `addons/custom/yiddish-core`:
די Fluent קאטאלאגן, Qt איבערזעצונגען, Rust בוי patch און Python/PyInstaller מקורות זענען אלע דארט.
דער גענויער Anki מקור איז commit `3890e12c9e48c028c3f12aa58cb64bd9f8895e30` פון
[ankitects/anki](https://github.com/ankitects/anki/tree/3890e12c9e48c028c3f12aa58cb64bd9f8895e30),
און די ספעציפישע native בוי איז אויך אין דער `codex/build-yiddish` branch פון דעם מאגר.
בוי אנווייזונגען: `addons/custom/yiddish-core/build/README.md`.
דער NSIS מקור און דער איינשטעלונגען מיזוג מנגנון זענען אין `installer`.

## לייסענסעס

אנקי איז אונטער GNU AGPL-3.0-or-later. די upstream headers און לייסענסעס פון יעדן צוגאב בלייבן גילטיג.
די רישוי טעקעס אינעם runtime און אין די תוסף תיקיות זענען געהיטן.
די צוגאב מקורות פון הפצת אנקי זענען אונטער זייערע אריגינעלע רישוי תנאים.

הודעה זו נשלחה באופן אוטומטי

די צוגאבן פון דער אויסגאבע מוזן לויפן מיטן יידישן runtime פון דעם Release; אן עקזיסטירנדיקער געווענליכער אנקי האט נישט דעם פארלאנגטן יידישן native קאטאלאג.
