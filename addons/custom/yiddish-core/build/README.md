# בויען דעם אידישן אנקי־קערן

די הפצה נוצט Anki 25.09.2 מיטן אפיציעלן מקור אין commit
`3890e12c9e48c028c3f12aa58cb64bd9f8895e30` פון
[ankitects/anki](https://github.com/ankitects/anki/tree/3890e12c9e48c028c3f12aa58cb64bd9f8895e30).
די 39 קאטאלאג־טעקעס אין `../locale/` האבן 1,733 Fluent־איינטראגן;
1,731 מעלדונגען און צוויי אינערליכע טערמינען. דער גאנצער ממשק איז אידיש אן ניקוד.
מזהים, משתנים, HTML, API און לערן־מקורות ווערן געהאלטן ווי אינעם מקור.

## וואס מען דארף צום בויען

- Windows x64 מיט Python 3.13, Rust 1.89.0 און protoc 31.1.
- דער אפיציעלער Anki־מקור מיט זיינע submodules, אין דעם אויבנדערמאנטן commit.
- דער זעלבער אומאפהענגיגער Python-3.13 / PyInstaller־קאמפיוטער־קערן פון דער הפצה.
- PyInstaller 6.19.0 צום איבערבויען דעם אינערליכן PYZ־ארכיון. דאס איז א בוי־מכשיר; מען דארף עס נישט צו נוצן די אינסטאלירטע הפצה.

## בויען דעם Rust־מנוע

לויט די אייגענע וועגן אויף אייער קאמפיוטער, עפנט א PowerShell־פענסטער און פירט אויס:

```powershell
py -3 build/prepare_native.py --upstream C:\build\anki --locale locale
Set-Location C:\build\anki
$env:PYO3_PYTHON = py -3.13 -c "import sys; print(sys.executable)"
$env:PROTOC = 'C:\build\protoc\bin\protoc.exe'
cargo +1.89.0 build --release --locked -p rsbridge --features native-tls
```

`prepare_native.py` באשטעטיגט דעם מקור־commit, אלע מזהים און משתנים,
און קאפירט די גאנצע אידישע קאטאלאג־טעקעס צו די אפיציעלע locale־וועגן.
ער פארריכט אויך די Windows־Python־וועג אינעם Rust־בוי־סקריפט,
אז ער זאל נוצן `PYO3_PYTHON` אנשטאט זיך פארלאזן אויפן upstream־`out/pyenv`.
א נארמאלער באפרייאונג־בוי מוז דורכגיין אן `--allow-incomplete`.

דער געבוירענער טעקע איז `target/release/rsbridge.dll`.
אין אן אומאפהענגיגער קאפיע פונעם פראגראם, נאכדעם וואס זי איז פארמאכט,
לייגט אים אין `_internal/anki/_rsbridge.pyd`.
מען זאל קיינמאל נישט איבערשרייבן דעם DLL פון א לויפנדיגן פראגראם.

## צוגרייטן דעם Windows־פראגראם

פון דעם תוסף־תיקיה פירט אויס, מיט די אייגענע אומאפהענגיגע וועגן:

```powershell
py -3.13 build/patch_runtime.py --app C:\build\app --backup-dir C:\build\private-originals --audit C:\build\private-runtime-audit.json
```

דער סקריפט נעמט די גענויע `.py`־מקורות וואס ליגן דא אין `runtime_sources/`,
באשטעטיגט זייערע SHA-256־חתימות מיט `runtime_sources/manifest.json`, און בויט איבער די באמת גענוצטע
מודולים `anki.lang`, `aqt` און `aqt.yiddish` אינעם אינערליכן PYZ־ארכיון פון `anki.exe`.
די אנדערע 1,600 מודולים ווערן געהאלטן בייט פאר בייט.
נאר צולייגן פונדרויסנדיגע `.py`־טעקעס איז נישט גענוג, ווייל דער געפרוירענער
אריינלאדער נוצט די מודולים אינעם EXE פריער.
מען דארף נישט קיין פונדרויסנדיגע `.py`־מקורות אינעם אריגינעלן פראגראם.

די אידישע שפראך, רעכטס־צו־לינקס־ריכטונג און Qt־תרגומים ווערן איינגעשטעלט פאר widgets און תוספים.
די הפצה האט אן אייגענעם מזהה פאר איין לויפנדיגן מופע און אן אייגענעם יומן,
אז זי זאל נישט זיך פארבינדן צו אן שוין אפענער געווענליכער Anki־ווערסיע.
`runtime.py` באשטעטיגט די גאנצע אידישע קאטאלאג מיט א גענויעם SHA-256־חתימה,
און האלט אפ א פראגראם מיט אן אנדערן אדער חלק'דיגן מנוע.

גיבויים און בוי־דוחות בלייבן באזונדער פונעם `app`־תיקיה וואס מען פארפאקט.
דער איבערגעבויטער EXE האלט נישט די חתימה פונעם פריערדיגן בינאר.
דער באפרייאונג־פראצעס דארף רעכענען נייע בינאר־חתימות נאך אלע ענדערונגען.
