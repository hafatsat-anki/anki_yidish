# Help menu icon sources

The SVG files in this directory were created for this project using basic
geometric shapes. They do not incorporate an external icon collection or the
Anki logo and follow the code license of this add-on.
The bronze stroke (`#a27b50`) matches the warm bookshelf palette of the main screen.

`info.svg` is a neutral About/information icon. The original Anki logo and
Anki's About dialog are not altered. The bug icon matches the original geometry
in `modern-theme/menu_icons.py`.

This note covers only these SVG files, not other legacy artwork in the repository.
