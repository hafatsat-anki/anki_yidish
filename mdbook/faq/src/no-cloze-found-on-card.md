# קיין אויסגעלאזטע ווערטער זענען נישט געפונען געווארן אינעם קארטל

<a id="כרטיסים-ריקים-בודדים"></a>

<h2>באזונדערע ליידיגע קארטלעך</h2>

ווען מען שאפט קארטלעך מיט אויסגעלאזטע ווערטער, ווערט יעדער נומער פון דער אויסלאזונג א באזונדערער קארטל. צום ביישפיל וועט דער פאלגנדער טעקסט שאפן דריי קארטלעך:

```
{{c1::זאת}} היא {{c2::דוגמא}} {{c3::פשוטה}}.
```

אויב איר רעדאקטירט דעם טעקסט שפעטער און נעמט אראפ אדער טוישט דעם נומער פון דער אויסלאזונג, קען דער פריער געשאפענער קארטל ווערן ליידיג. צום ביישפיל:

```
{{c1::זאת}} היא {{c2::דוגמא}}
```

און

```
{{c1::זאת}} היא {{c2::דוגמא}} {{c1::פשוטה}}.
```

ביידע ענדערונגען וועלן מאכן קארטל 3 ליידיג. ווען איר וועט זען קארטל 3, וועט איר באקומען א מעלדונג אז דער קארטל איז ליידיג. מען קען נוצן "ליידיגע קארטלעך" אין מעניו > אוסף־מכשירים אינעם הויפטפענסטער פון דער קאמפיוטער־ווערסיע, כדי אראפצונעמען ליידיגע קארטלעך. קוקט ערשט איבער די געמאלדענע ליידיגע קארטלעך; אין פאל פון א ספק, מאכט א גיבוי מיטן מעניו־איינטראג "עקספארטירן" איידער איר גייט ווייטער.

<a id="כל-כרטיסי-ההשלמות-ריקים"></a>

<h2>אלע קארטלעך מיט אויסגעלאזטע ווערטער זענען ליידיג</h2>

אויב איר האט בטעות געטוישט אייער קארטל־תבנית, קען דאס אפהאלטן די אויסלאזונגען פון זיך ריכטיג ווייזן. אויב דאס איז געשען, רעדאקטירט איינעם פון די פראבלעמאטישע קארטלעך און שרייבט זיך אויף דעם נאמען פונעם ערשטן פעלד; געווענליך הייסט ער "Text". דערנאך:

- דריקט אויפן קנעפל "קארטלעך..."
- טוישט דעם פארנט־טעקסט צו:

  ```
  {{cloze:Text}}
  ```

- טוישט דעם הינטער־טעקסט צום זעלבן.

אויב אייער פעלד האט געהייסן אנדערש ווי "Text", טוישט דעם ווארט "Text" צום פעלד־נאמען.
